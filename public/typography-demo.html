Can we use it? Probably yes, but read the license first

The launch post says "Free to use." That usually means free for commercial use too, but "free" can mean several things. Before Myra ships these fonts, check three things in the license file that comes with the download from timeless.co/type:

  • Commercial use: is it allowed in a product, or only in personal projects?
  • Web embedding: can we self-host the .woff2 files on Myra's server? An SIL Open Font License (OFL) allows this.
  • Attribution / renaming: do we need a credit line? OFL lets you bundle the fonts but not sell them on their own.

Until the files are added, this page uses close free stand-ins (Host Grotesk, Instrument Sans, Source Serif 4, Literata). Drop the real Timeless font files below to see the real thing.

One family, four jobs

Each style gets one clear job in Myra. Swapping the whole family together keeps it feeling like one brand, not four fonts.

Myra go

What changing it would take

If we adopt it, the code change is small, because Myra already sends every font through two variables.

StepWhatWhere
1Confirm the license allows commercial use and web embedding.License file in the download
2Add the variable .woff2 files (roman + italic) to the repo.src/app/fonts/
3Load them with next/font/local instead of the Inter / Newsreader Google imports.src/app/layout.tsx
4Point --font-serif / --font-sans at Timeless; add --font-grotesk and --font-text.src/app/globals.css
5Use Grotesk on the logo + key facts, Text on long notes. Keep Noto Serif SC for Chinese.nav.tsx, detail page
